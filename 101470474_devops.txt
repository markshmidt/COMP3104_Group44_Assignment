##------ COURSE SUMMARY -----##
The COMP 3104 DevOps course is a computer programming course for COmputer Programming and Analysis program (T177) In George Brown College that teaches students to apply DevOps practices to streamline software delivery and ensure reliable release management.

##------ COURSE DESCRIPTION -----##
In this course students can learn the procedures, protocols and best practices that a DevOps engineer brings to a workplace environment to increase productivity. Analyze and evaluate various developer operation implementations available and implement hands-on work using industry standard toolkit. Create solutions to complex business problems by adhering to the core responsibilities of DevOps.
